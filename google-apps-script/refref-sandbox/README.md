`PaidInvoice.gs` is also staged locally and makes no network calls. It prepares a RefRef purchase event only after the Square invoice is marked fully paid and the owner supplies the verified Square customer ID, invoice ID, paid amounts, and the customer's paid-order number. The paid-history builder requires all prior paid Square invoice IDs through the current invoice. RefRef may accept an event while its reward evaluation is still pending; do not grant Jonezie Cash until the actual RefRef reward is confirmed. Run `node --test scripts/test-refref-paid-invoice.cjs` to verify the payload rules. Neither file is installed in Google Apps Script yet.
